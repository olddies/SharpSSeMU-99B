## What is NOT in this repository

The following are deliberately excluded (see `.gitignore`) and must be obtained by you, from a
source you are legally entitled to use:

| Excluded | Why |
|---|---|
| `MuClient/` — the original 0.99B client (`main.exe`, `Main.dll`, `Data/`) | proprietary binaries and game assets |
| `MuServer99B/` — the original SSeMU 0.99B server package (binaries, `Data/` tables) | third-party package; the game data tables are proprietary |
| `Source/` — SSeMU C++ emulator sources | third-party source, used as the verification reference |
| Client `Data/` (models, textures, sounds, UI) under `src/bin/Data` | proprietary game assets |
| SDL, SDL_mixer, Dear ImGui sources | fetched by `scripts/setup-thirdparty.*` from their upstream repositories |

**Do not commit or redistribute these files**, in this repository or in forks. Contributions that
include game assets or extracted proprietary data will not be accepted.

## Provenance of what *is* included

| Part | Origin |
|---|---|
| `SharpSSeMU/` | A C#/.NET re-implementation of the SSeMU 2.1.7 (0.99B) server. Written for this project, **derived from the behaviour and structure of the SSeMU C++ emulator**, which it was ported and verified against. Source comments cite the original files/lines. |
| `SharpSSeMU/src/MuServer.GameServer/Data/GameServerInfo - *.dat` | Configuration files **authored for this project**: they hold the setting names the C# server reads and their default values, with our own grouping and headers. No text, comments or layout from the SSeMU package is included. SSeMU is a commercial product of SetecSoft Development (all rights reserved, no public license); its own files and data tables are **not** redistributed here. |
| `MuMain-099B/` | A **fork of [sven-n/MuMain](https://github.com/sven-n/MuMain)** (itself based on Louis's Main5.2 sources and community work by Qubit, Nitoy and others) with a 0.99B network layer added. Upstream credits are preserved in its README. |
| `MuMain-099B/src/Protocol099B/Protocol099B.generated.h` | Generated by `tools/protogen` from the SSeMU emulator headers (struct layouts only). |
| `MuMain-099B/src/ThirdParty/{json.hpp,stb}` | nlohmann/json (MIT), stb (public domain / MIT). |
